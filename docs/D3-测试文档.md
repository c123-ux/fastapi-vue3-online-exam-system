## 1. 测试范围与策略

| 层 | 范围 | 依赖 | 说明 |
|---|---|---|---|
| 单元（TC-U） | 判分引擎、答案规范化、截止时间与窗口下限计算、题型校验矩阵、状态守卫纯逻辑 | **零依赖**（不连 MySQL/Redis） | 入参用 dataclass（`QuestionSpec`/`AnswerSpec`），毫秒级，可在无基础设施环境跑 |
| 集成（TC-I） | 全链路接口行为、RBAC 判定顺序、防重并发、超时清算、续考不续时、统计数字、答案泄露 | 真实 MySQL 8.0.46@3307（`exam_test`）+ 真实 Redis 5.0.14.1（db1） | 用 `TestClient`；服务与 DB/Redis 不通则 **fail-fast 并打印启动命令**（不算 skip） |
| 静态（TC-S） | 源码禁用 SQL 时间函数、路由可达性、Alembic 迁移可重放、响应字段白名单 | 读源码/元数据 | 把"只有真库/真框架才暴露"的坑固化成断言 |

**明确不测**：Vue3 前端（决策 #8 本期不做）、随机抽题（P1 预留）、限流与试卷缓存键（P1 预留不实现）、性能达标（NFR-01 已降为观察项，见 D1）。

### 2.1 环境（全部为本机实测事实）
| 项 | 值 |
|---|---|

### 2.2 conftest 职责（session 级）
1. 探测 MySQL/Redis；任一不通 → `pytest.exit` 并打印 `scripts/start_redis.ps1` 等启动命令（**环境缺失=失败，不是 skip**）；
2. `DROP DATABASE IF EXISTS exam_test; CREATE DATABASE exam_test utf8mb4/utf8mb4_unicode_ci`；
3. Alembic 以 programmatic 方式把 URL 指向 `exam_test` 后 `upgrade head`；
4. 建 teacher01 / teacher02 / stu01 / stu02 与 §2.3 题库、试卷模板；
5. function 级：每用例回滚事务或清理本用例产生的记录，保证 `UNIQUE(paper_id, student_id)` 不互相污染。
